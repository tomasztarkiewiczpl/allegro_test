Seller Market Analyzer

Cel aplikacji

Aplikacja analityczna rozwijana w Pythonie. Jej celem jest analiza produktów, ofert i trendów na platformie Allegro.

Funkcjonalności

Planowane są porównania cen, analiza konkurencji, monitorowanie trendów i prezentacja danych na wykresach.

Integracja z Allegro

Planowana integracja z oficjalnym REST API Allegro z wykorzystaniem OAuth 2.0. Aplikacja będzie korzystać wyłącznie z autoryzowanych zasobów i uprawnień. Zakres uprawnień zostanie określony przed wdrożeniem integracji.

Bezpieczeństwo

Aplikacja będzie działać początkowo lokalnie. Dane uwierzytelniające oraz tokeny OAuth nie będą udostępniane publicznie.

Status

Projekt w fazie rozwoju i testów.
